# Kasenyi Bay Hotel 🌊

A 4-page responsive website for a fictional lakeside hotel on Lake Victoria, Entebbe, Uganda.

## Pages
- `index.html` — Home page with hero section, hotel features, and room previews
- `about.html` — Hotel story, amenities, and location
- `booking.html` — Booking form with live price calculator and date validation
- `contact.html` — Contact info and message form

## Built With
- HTML5
- CSS3
- JavaScript (form validation, live price calculation, mobile nav menu, scroll animations)

## Features
- Fully responsive design (mobile, tablet, desktop)
- Interactive booking form — calculates total price live based on room type and number of nights
- Form validation with error messages
- Mobile hamburger navigation menu
- Scroll-triggered animations
